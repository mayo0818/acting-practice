# 연기 연습실 🎭 — acting-practice

배우를 위한 연기 연습 웹앱. 단일 HTML 파일로 만들어져 인터넷 연결 없이도 동작합니다.

**사용:** https://mayo0818.github.io/acting-practice/

아이폰 Safari에서 위 링크를 열고 **공유 → 홈 화면에 추가**를 누르면 앱처럼 전체 화면으로 실행됩니다.

## 기능
- 📜 대본 · 독백 — 실제 영화·드라마 독백 6편(이태원 클라쓰, 미생, 나의 아저씨, 나의 해방일지, 기생충, 건축학개론)과 샘플 4편, 내 대사 가리기, 프롬프터 자동 스크롤, 녹음
- 🎲 즉흥 연기 — 인물·상황·목표·감정 랜덤, 준비/연기 타이머, 돌발 디렉팅
- 🗣️ 발성 · 발음 — 복식호흡 가이드, 딕션 문장, 감정 톤 룰렛
- 📝 연습 기록 — 연습 시간·메모 저장 (기기 localStorage)
