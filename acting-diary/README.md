# 연기 일기 (Acting Diary)

매일의 연기를 영상과 대사로 남기는 배우의 기록장.
아이폰 사파리에서 앱처럼 열리도록 만든 정적 웹앱입니다.

- 주소: https://mayo0818.github.io/acting-practice/acting-diary/
- 설치: 사파리 공유 → **홈 화면에 추가**

## 무엇을 하는 앱인가

1. **기록** — 앱 안에서 바로 카메라로 연기 영상을 찍고, 그 자리에서 말한 대사를 실시간으로 받아 적습니다. 사진 앱에 있는 영상을 올려도 같은 방식으로 정리됩니다.
2. **정리** — 작품·배역·대사·감정 태그·별점·메모를 남겨 한 편의 장면으로 저장합니다. 썸네일과 촬영 시각은 자동으로 붙습니다.
3. **다시 보기** — 날짜별 타임라인, 월 달력, 대사·작품·배역·감정 검색으로 지난 장면을 꺼내 봅니다.
4. **AI 분석(선택)** — Gemini API 키를 넣으면 영상에서 대사를 뽑아 적고 감정선·대사 전달력·시선/표정을 짚어 줍니다. 키가 없어도 모든 기능을 그대로 쓸 수 있습니다.

## 쓰는 법

### 카메라로 기록
1. 아래 **기록** 탭 → 카메라 권한 허용
2. 셔터를 눌러 녹화 시작 (최대 10분)
3. 말한 대사가 바로 아래 '실시간 대사 인식'에 쌓입니다
4. 셔터를 다시 눌러 종료 → 자동으로 대사가 채워진 작성 화면으로 이동

> 실시간 인식은 브라우저(사파리)의 음성 인식을 씁니다. 기종이나 통신 상태에 따라 늦거나 비어 있을 수 있고, 그때는 대사를 직접 적으면 됩니다.

### 사진의 영상 올리기
**기록** 탭 → **영상 올리기** → 사진 앱에서 선택.
파일의 촬영 시각이 기록 시각으로 들어갑니다.

### AI 분석 붙이기
1. 오른쪽 위 설정 → **Gemini API 키** 입력 후 저장 (https://aistudio.google.com/apikey 에서 무료 발급)
2. 작성 화면에서 **분석하기** → 대사 자동 입력 + 피드백
3. 키는 이 브라우저(localStorage)에만 저장되고, 분석할 때만 구글 서버로 영상이 전송됩니다

18MB가 넘는 영상은 분석되지 않습니다. 그때는 대사를 직접 적어 저장하면 됩니다.

## 데이터가 있는 곳

- 영상과 기록은 **이 기기 브라우저의 IndexedDB(`acting_diary_db`)** 에만 저장됩니다. 서버로 올라가지 않습니다.
- 설정 → **JSON 내보내기**로 대사·메모·별점·썸네일을 백업할 수 있습니다. JSON에는 영상 파일이 들어가지 않으므로, 영상을 옮기려면 아이폰 사진 앱에서 원본을 따로 보관하세요.
- 브라우저 저장 공간을 비우거나 시크릿 모드로 열면 기록이 사라질 수 있습니다. 홈 화면에 추가해 쓰는 편이 안전합니다.
- 기기 저장 공간이 부족하면 저장에 실패할 수 있습니다. 오래된 장면을 정리하면 공간이 돌아옵니다.

## 개발 메모

- 빌드 도구 없는 단일 정적 앱: `index.html` + `app.css` + `app.js` (+ `manifest.json`, 아이콘)
- 외부 의존성은 Pretendard 웹폰트(CDN) 하나뿐이며, 없으면 애플 SD 고딕으로 대체됩니다
- iOS 사파리 대응: `100dvh`, `env(safe-area-inset-*)`, `playsinline`, 44px 이상 터치 영역, `MediaRecorder` MP4/WebM 폴백, 라벨 오버레이 방식 파일 선택
- 화면 폭 940px 이상에서는 기록을 두 줄로 펼칩니다
