# 🎧 iPad DJ 스튜디오 · 런치패드

아이패드 가로 화면에서 쓰는 **2덱 DJ 믹서 + 16패드 런치패드** 웹앱(PWA)입니다.
외부 라이브러리·CDN 없이 동작하는 정적 웹앱입니다.

## 🌐 바로 열기

- **웹 버전 (GitHub Pages)**: https://mayo0818.github.io/acting-practice/dj-studio/
- 아이패드 Safari로 위 주소를 열면 바로 실행됩니다. 공유 → **홈 화면에 추가**로 앱처럼 쓸 수 있습니다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 앱 화면 (2덱 + 16패드) |
| `css/styles.css` | 스타일 |
| `js/audio-engine.js` | Web Audio 엔진 (마스터·스테레오·VU) |
| `js/deck.js` | 데크: 파형·조그휠·핫큐·루프·피치·SYNC·EQ·필터 |
| `js/pads.js` | 런치패드 16패드·내장 신스 사운드 |
| `js/app.js` | 화면 배선·믹서·크로스페이더·오디오 언락 |

외부 CDN·라이브러리 의존성은 없습니다. 인터넷이 없는 곳에서 쓰려면 저장소를 내려받아 `index.html`을 열거나, 페이지를 한 번 연 뒤 Safari의 '공유 → 홈 화면에 추가'로 저장해 두면 됩니다.

## 아이패드에서 쓰기

1. 위 웹 주소를 Safari로 엽니다. (오프라인용으로는 저장소를 내려받아 `index.html`을 파일 앱에서 열어도 됩니다.)
2. 화면을 한 번 터치하면 상단 배지가 **오디오 켜짐**으로 바뀌고 소리가 납니다.
3. Safari 공유 → **홈 화면에 추가**를 하면 주소창 없이 앱처럼 열립니다.

> 호스팅(GitHub Pages, 개인 서버 등)에 올려 접속해도 똑같이 동작합니다. 파일은 100% 자체 포함이라 CDN·네트워크 요청이 없습니다.

## 기능

### 데크 A / B (턴테이블)
- **곡 불러오기**: ＋ 곡 버튼 또는 데크로 파일 드래그&드롭 (MP3·M4A·WAV·AAC·OGG·FLAC)
- **파형**: 실제 오디오 파형 렌더링, 재생 위치 커서, 손가락 스크러빙, 루프 구간·CUE·핫큐 마커
- **조그휠**: 드래그로 스크래치(위치 이동), 재생 중 자동 회전 애니메이션
- **전송**: CUE(저장/복귀), 재생·일시정지, SYNC
- **핫큐 1~4**: 한 번=저장, 다시=점프, 길게(0.55초)=삭제
- **루프 1/2/4/8박**: 현재 위치 기준, 다시 누르면 해제 (곡 끝에서는 시작점을 당겨 온전한 길이 보장)
- **피치 ±16%** 슬라이더 + **BPM 자동 추정**(간이 온셋 자기상관) 및 실효 BPM 표시
- **SYNC**: 상대 데크의 실효 BPM에 속도를 맞추고 박자 위상까지 정렬 · **다시 누르면 해제**(원래 속도 0.0%로 복귀, 피치 슬라이더를 직접 움직여도 해제)
- **3밴드 EQ** LOW/MID/HIGH (-26~+6 dB) · **필터 노브**(왼쪽 LPF / 오른쪽 HPF, 두 번 탭 = 중앙) · **채널 볼륨 페이더**

### 믹서
- **크로스페이더** (등청감 cos/sin 커브)
- **마스터 볼륨** + **스테레오 VU 미터**(세그먼트 LED, 피크 홀드, dB 스케일)
- EQ·필터·피치 초기화 / 전체 정지

### 런치패드 (4×4)
- 내장 16종 신스 사운드: 킥 · 스네어 · 클랩 · 하이햇 · 오픈햇 · 808 · 림샷 · 크래시 · 탐 · 에어혼 · 사이렌 · 스크래치 · 라이저 · 드롭 · 레이저 · 코드
- 패드별 **내 오디오 파일 할당**(선택 → 파일 할당) · 초기화
- 패드 모드 **원샷 / 홀드 / 루프**, **패드 볼륨**

### 터치·iOS 대응
- `pointerdown/move/up` 기반 **멀티터치**(한 손 패드 + 다른 손 크로스페이더·조그휠 동시 조작)
- **모든 슬라이더(피치·채널 볼륨·EQ·마스터·크로스페이더·패드 볼륨)를 포인터로 직접 제어** — 트랙 아무 곳이나 짚으면 그 자리 값으로 바로 이동하고, 끄는 동안 연속으로 따라옵니다. iOS Safari 의 `input[type=range]` 처럼 작은 썸을 정확히 집지 않아도 되고, `rotate(-90deg)` 로 세운 슬라이더도 좌표를 변환해 동작합니다.
- **피치 바를 두 번 두드리면 0.0% 로 초기화**(SYNC 표시도 함께 해제)
- `touch-action:none` 으로 스크롤·확대 튐 방지, 세로 스크롤 없는 한 화면 레이아웃(1180×820 / 1024×768)
- `pointerdown / touchstart / touchend / click / mousedown / keydown` 모든 제스처에서 **동기적으로 `AudioContext.resume()`** + 1샘플 무음 재생으로 잠금 해제
- `navigator.audioSession.type = 'playback'`(iPadOS 16.4+)과 무음 `<audio>` 요소로 **아이패드 무음 스위치가 켜져 있어도 소리**가 납니다
- 파일 선택은 투명한 `<input type=file>`을 버튼 위에 겹쳐(iOS는 `display:none` 입력의 프로그램 클릭을 무시) **파일 앱에서 바로 고를 수 있습니다**
- 파일은 `FileReader`로 읽은 뒤 디코딩이 끝난 다음에 입력을 비워 iOS의 조기 초기화 문제를 피함
- 재생 버튼은 `click` 한 경로만 쓰고 80ms 중복 가드를 두어 터치/클릭이 겹쳐도 한 번만 토글
- 앱을 벗어났다 돌아오면(`visibilitychange`/`pageshow`/`focus`) 오디오를 다시 깨워 재생 지점을 이어감
- PWA 메타태그(apple-mobile-web-app-capable, 상태바 스타일, 테마 컬러, 인라인 SVG 아이콘, 매니페스트)

### 단축키(키보드에서도)
- 패드: `1 2 3 4 / Q W E R / A S D F / Z X C V`
- 데크 A 재생 `Space`, 데크 B 재생 `Enter`, 크로스페이더 `← →`

├── js/audio-engine.js    AudioContext·마스터 버스(컴프레서·스테레오 분석)·VU·BPM 추정
├── js/deck.js            데크 1대: 파형·조그휠·전송·핫큐·루프·EQ·필터·페이더
├── js/pads.js            16패드 신스 사운드 + 내 샘플 할당 + 모드

## 빌드 · 테스트

```bash
cd projects/ipad-dj-pad
python3 tests/make_fixtures.py     # 테스트 음원 생성 (최초 1회)
python3 build.py                   # downloads/ipad-dj-studio.html 갱신
python3 tests/test_app.py          # 실제 브라우저 자동 검증 + 미리보기 스크린샷
```

테스트는 곡 로드·파형 렌더링·재생·스크러빙·핫큐·조그휠·루프·EQ·필터·피치·크로스페이더·
SYNC·16패드 전수 트리거·커스텀 샘플 할당·패드 모드·멀티터치·레이아웃(두 해상도)·
콘솔/페이지 오류 0건까지 확인합니다.

## 알아둘 점

### 소리가 안 들릴 때 (아이패드)
1. 화면 아무 곳이나 **한 번 탭** — 상단 배지가 **오디오 켜짐**(초록)인지 확인합니다.
2. 아이패드 **옆면 무음 스위치**와 볼륨 버튼을 확인합니다. 이 앱은 iPadOS 16.4 이상에서 오디오 세션을 `playback`으로 잡아 무음 스위치를 무시하지만, iOS 16.3 이하는 시스템 정책상 무음 스위치를 따릅니다.
3. 곡이 안 열리면 **MP3 / M4A / WAV**로 다시 시도합니다. 애플뮤직 보호 파일(`.m4p`)과 MIDI는 지원하지 않습니다.
4. 그래도 재생이 멈춰 있으면 페이지를 새로 고친 뒤 화면을 한 번 탭합니다. (앱을 벗어났다 돌아오면 자동으로 다시 깨어납니다.)

- BPM 추정은 **간이 알고리즘**(200 Hz 엔벨로프 온셋 자기상관)이라 리듬이 뚜렷한 곡에서 잘 맞고,
  드럼이 거의 없는 곡은 오차가 날 수 있습니다. SYNC은 추정값 기준입니다.
- 피치 슬라이더는 턴테이블처럼 **속도와 음정이 함께** 바뀝니다(키 고정 없음).
- 매니페스트는 data URI라 일부 브라우저가 무시할 수 있습니다. iOS에서는
  `apple-mobile-web-app-capable` 메타태그로 홈 화면 전체화면이 동작합니다.
