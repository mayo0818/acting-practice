사용 안내

1. 소리 켜기

iOS는 첫 터치 전까지 소리를 막습니다. 화면 아무 곳이나 한 번 누르면 상단 배지가 오디오 켜짐으로 바뀝니다.

아이패드·아이폰 옆면의 무음 스위치가 켜져 있어도 이 앱은 소리가 나도록 오디오 세션을 playback으로 잡습니다(iPadOS 16.4 이상). 그래도 소리가 안 들리면 볼륨 버튼과 무음 스위치를 한 번 확인해 주세요.

2. 곡 불러오기

DECK A / DECK B의 ＋ 곡 버튼을 누르고 파일 앱에서 MP3·M4A·WAV·AAC를 고르세요. 데크 위로 파일을 끌어다 놓아도 됩니다. 곡을 넣으면 파형과 BPM이 자동으로 표시됩니다.

3. 데크 조작

  • 파형 — 문지르면 그 위치로 이동합니다.
  • 조그휠 — 드래그하면 스크래치하듯 위치가 움직이고, 재생 중에는 휠이 돌아갑니다.
  • CUE — 재생 중 누르면 큐 지점으로 돌아가 멈추고, 멈춰 있으면 큐 지점부터 재생합니다. 큐가 없으면 지금 위치를 큐로 저장합니다.
  • 핫큐 1~4 — 한 번 누르면 지금 위치 저장, 다시 누르면 그 지점으로 점프, 길게 누르면 삭제.
  • 루프 1/2/4/8박 — 지금 위치부터 그 박자만큼 반복합니다. 같은 버튼을 다시 누르면 해제.
  • 피치 ±16% — 슬라이더로 속도(과 음정)를 바꿉니다. SYNC는 반대편 데크 BPM에 속도와 박자를 맞춥니다.
  • EQ LOW/MID/HIGH · 필터 — 필터 노브는 왼쪽이 로우패스(LPF), 오른쪽이 하이패스(HPF)입니다. 두 번 두드리면 중앙으로 돌아갑니다.

4. 런치패드

16개 사운드가 내장되어 있어 파일 없이도 바로 연주할 수 있습니다. 패드를 누른 뒤 파일 할당을 누르면 내 오디오 파일이 그 패드에 들어갑니다.

원샷 끝까지 재생 · 홀드 누르는 동안만 · 루프 누르는 동안 반복.

5. 홈 화면에 추가

Safari의 공유 버튼 → 홈 화면에 추가를 하면 주소창 없이 전체 화면 앱처럼 열립니다. 인터넷 연결 없이도 동작합니다.
