# HandBand — Guided Gesture Synth (가로모드)

손가락 모양만 따라 하면 코드가 울리는 인스타 릴스 스타일의 **가이드 신스**.
위에는 노래방처럼 가사와 코드가 흐르고, 아래 가이드 카드가 지금 쳐야 할 코드와
왼손·오른손 모양을 알려 줍니다. 화면에 보이는 그대로 촬영됩니다.

`https://mayo0818.github.io/acting-practice/handband/`

## 쓰는 법

1. **가로로** 돌려서 연다. (세로로 열어도 깨지지는 않지만 가로가 기본)
2. `카메라로 시작` → 카메라·마이크를 허용한다.
3. **내 속도(My Pace)**: 가이드에 나온 손가락 개수를 만들면 그 코드가 울리고,
   잠깐 유지하면 다음 코드로 넘어간다. 손가락을 바꾸면 바로 다음 코드.
4. **자동(Auto-play)**: ▶ 를 누르면 BPM에 맞춰 가사·코드가 자동으로 흐른다.
5. `촬영` → 3초 카운트다운 → 캔버스(카메라+가사+가이드) + 신스 + 마이크가
   `.mp4`(Safari) 또는 `.webm`으로 저장된다.

## 손가락 약속

| 손 | 하는 일 |
|---|---|
| **왼손 1~5** | 그 구간의 몇 번째 코드인지 (엄지 포함 개수) |
| **오른손 편 손(4~5)** | 기본 묶음 · 연주 |
| **오른손 3 / 2 / 1** | 다음 묶음 (한 구간에 코드가 6개 이상일 때) |
| **오른손 주먹** | 뮤트 |

카메라가 없거나 손 인식이 안 되면 하단 `1 2 3 4 5` 버튼으로 같은 동작을 한다.
화면상 왼손·오른손이 뒤바뀌면 설정 → 카메라 → `왼손·오른손 바꾸기`.

## 내장 악보

- 잔나비 — 주저하는 연인들을 위해 (B♭)
- 홍이삭 — 내사랑 내곁에 (E♭, 폭싹 속았수다 OST)
- 김현식 — 내사랑 내곁에 (G)
- 자유 잼 (Cmaj7 – Am7 – Fmaj7 – G7)

악보 → `새 악보` / `이 곡 편집` 에서 직접 쓸 수 있고 `localStorage`에 남는다.

```
#1절
[Eb]나의 모든 [Gm]사랑이 [Ab]떠나가는 [Eb]날이
[Eb]당신의 그 [Fm]웃음 뒤에서 [Bb7]함께 하는데

#후렴
[Ab]저 여린 가지 [Bb7]사이로 ...
```
`#`으로 시작하는 줄이 구간, 빈 줄은 쉬는 자리. 코드는 가사 글자 위에 그대로 붙는다.

## 카메라 방향

`getUserMedia`에 `1280×720`(가로)을 우선 요청하고, 캔버스는 화면 비율에 맞춰
항상 `cover`로 꽉 채운다(세로 띠·검은 여백 없음). 기기에 따라 영상이 돌아오면
설정 → 카메라 → `90° 회전`(0/90/180/270)과 `좌우 반전`으로 맞춘다.
손 좌표는 화면에 그려지는 영상과 같은 변환을 거쳐 찍히므로, 화면의 왼손이
그대로 왼손으로 인식된다.

## 파일

```
handband/
  index.html        화면 골격 + 시트(악보·설정·편집·녹화 미리보기)
  css/style.css     글래스 UI, 가로/세로 대응
  js/chords.js      코드 파서 · 보이싱 · 조옮김
  js/score.js       악보 해석(코드-가사 배치, 스텝, 손가락 배정)
  js/songs.js       내장 악보 4곡
  js/audio.js       Web Audio 신스 4프리셋 + 리버브/코러스 (iOS unlock)
  js/hands.js       MediaPipe HandLandmarker (양손, 손가락 개수 안정화)
  js/stage.js       캔버스 무대(카메라·노래방 가사·가이드 카드·손 뼈대)
  js/app.js         진행 상태·컨트롤·카메라·녹화·악보 편집
```

카메라 영상은 기기 안에서만 처리되고 서버로 보내지 않는다(손 인식 모델만 CDN에서 받는다).
