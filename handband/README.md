# HandBand Reels 🎹

손 제스처로 코드를 연주하고, 그 화면을 그대로 릴스 영상으로 찍는 웹 앱입니다.
HandBand.app의 원형 코드 휠 + 인스타그램 릴스 감성으로 만들었어요.

**바로 쓰기:** https://mayo0818.github.io/acting-practice/handband/

아이폰 Safari에서 열고 **공유 → 홈 화면에 추가**를 누르면 앱처럼 전체 화면으로 쓸 수 있어요.

## 하는 일

- **손으로 연주** — 카메라 앞에서 손을 원형 휠 위로 옮기면 그 칸의 코드가 울립니다. 엄지와 검지를 벌리면 커지고, 오므리면 잦아들어요. 중심에서 멀어질수록 소리가 밝아집니다.
- **카메라가 없어도** — 권한을 거절하거나 카메라가 없으면 자동으로 포인터 모드로 바뀝니다. 휠을 직접 누르거나 1~8 키로도 연주돼요.
- **악보 추가·편집** — 곡 제목, 구간(1절·후렴…), 코드 진행, 가사를 넣고 저장하면 기기에 남습니다(localStorage). 코드는 `Ebmaj7`, `Bb7`, `Fm7`, `Gsus4`, `Bdim`, `C/E`, `D/F#`처럼 어떤 표기든 읽어요.
- **기본 악보 4곡** — 잔나비 「주저하는 연인들을 위해」(원곡 B♭), 홍이삭 「내사랑 내곁에」(E♭), 김현식 「내사랑 내곁에」(G), 자유 잼.
- **조옮김** — ♭/♯ 버튼으로 -6~+6 반음. 홍이삭 E♭ 악보를 김현식 G로 바꿔 부를 수도 있어요.
- **사운드** — Warm Pad / Electric Piano / Lush Synth / Music Box, 리버브와 코러스 포함.
- **촬영** — 3초 카운트다운 후 화면(카메라 미러 + 휠 + 가사 + 손 관절)과 소리(신스 + 마이크)를 함께 녹화합니다. 끝나면 바로 미리보기가 뜨고 `.mp4`(아이폰) 또는 `.webm`으로 저장·공유돼요.

## 아이폰 · 아이패드에서 확인할 것

- 첫 화면의 **시작하기**를 눌러야 카메라·소리 권한이 열립니다.
- 녹화할 때 마이크 권한을 따로 물어봐요. 거절하면 신스 소리만 담깁니다.
- 소리는 스피커로 되돌리지 않아요(하울링 방지). 마이크는 녹화 파일에만 들어갑니다.
- 저장은 파일 앱으로 내려가요. 사진 앱에 넣으려면 미리보기의 **공유 → 동영상 저장**을 쓰세요.
- 손 인식은 첫 실행 때 모델(약 3MB)을 내려받습니다. 인터넷이 필요해요.

## 파일

```
handband/
  index.html
  css/style.css
  js/chords.js   코드 파서 · 보이싱
  js/songs.js    기본 악보
  js/audio.js    Web Audio 신스
  js/hands.js    MediaPipe HandLandmarker
  js/app.js      화면 · 제스처 · 촬영 · 편집
```

카메라 영상은 기기 안에서만 쓰고 어디로도 보내지 않습니다.

기본 악보의 코드 진행은 공개된 코드악보를 참고했고, 가사는 연주를 돕는 짧은 안내입니다.
가사의 권리는 각 원저작자에게 있습니다.
