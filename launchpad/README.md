# 🎹 iPad 런치패드 루프 스테이션

아이패드 Safari에서 바로 쓰는 **48패드 런치패드 + 실시간 루프 스테이션** (단일 HTML, 외부 의존성 0).

- **웹 버전**: https://mayo0818.github.io/acting-practice/launchpad/
- 홈 화면에 추가하면 전체화면 앱처럼 동작합니다.
- 소스·테스트: `projects/ipad-launchpad/` (단일 HTML은 `build.py`로 재생성)

기능: 4×4 × 3뱅크(A 드럼·808 / B 베이스·코드 / C 리드·FX·보컬) 48사운드 · 멀티터치 LED 패드 ·
내 오디오 파일·마이크 녹음(IndexedDB 저장) · BPM/마디/메트로놈/박자 보정 · 4레이어 오버더빙 루프 ·
실행 취소·정지·전체 지우기 · 로우패스/하이패스 필터·딜레이·리버브·마스터 볼륨.
