사용 안내

1. 소리 켜기

iOS는 첫 터치 전까지 소리를 막습니다. 화면 아무 곳이나 한 번 누르면 상단 배지가 오디오 켜짐으로 바뀝니다. 아이패드 옆면의 무음 스위치가 켜져 있어도 소리가 나도록 오디오 세션을 playback으로 잡습니다(iPadOS 16.4 이상).

2. 패드 연주 · 3뱅크 48소리

가로 4 × 세로 4 = 16패드가 한 화면에 있고, 상단 A / B / C 뱅크를 바꾸면 모두 48개 소리를 쓸 수 있습니다. 파일 없이도 바로 연주됩니다.

  • A — 킥 · 스네어 · 클랩 · 하이햇 · 탐 · 808 · 크래시
  • B — 서브베이스 · 베이스 · 코드(Cmaj7·Am7·Fmaj7·G7) · 패드 · 아르페지오
  • C — 리드 · 라이저 · 임팩트 · 레이저 · 사이렌 · 보컬 톤

여러 손가락으로 동시에 쳐도 됩니다(멀티터치).

3. 내 소리 넣기 (파일 / 마이크)

패드 편집을 켜고 원하는 패드를 누른 뒤, 오른쪽 편집 칸에서

  • 오디오 파일 — 파일 앱에서 MP3 · WAV · M4A · AAC 선택
  • 마이크 녹음 — 누르고 소리를 낸 뒤 다시 눌러 끝내기 (최대 10초, 앞뒤 무음 자동 정리)
  • 기본 소리 — 내장 사운드로 되돌리기

패드마다 이름 · 색상 · 볼륨 · 재생 방식을 정할 수 있고, 넣은 소리는 아이패드(IndexedDB)에 저장되어 새로고침해도 그대로 남습니다.

원샷 한 번 누르면 끝까지 · 홀드 누르는 동안만 · 루프 누르는 동안 반복.

4. 실시간 루프 스테이션

  • BPM 60~180, 마디 1 / 2 / 4 / 8로 루프 길이를 정합니다.
  • ● 녹음을 누르고 아무 패드나 한 번 치면 그 순간이 루프의 시작점이 됩니다. 정한 마디가 끝나면 자동으로 처음부터 계속 반복됩니다.
  • 루프가 도는 동안 다른 패드를 계속 쳐서 겹쳐 녹음(오버더빙)할 수 있습니다. 레이어 1~4에 나눠 담으면 마디마다 따로 뮤트·재생·지우기가 됩니다.
  • 박자 보정이 켜져 있으면 친 타격이 16분음표 격자에 맞춰 기록됩니다. 끄면 친 그대로 기록됩니다.
  • 실행 취소는 방금 겹친 타격 묶음만 되돌립니다. 정지는 멈추고, 전체 지우기는 두 번 눌러 전부 삭제합니다.
  • 메트로놈을 켜면 첫 박에 강세가 붙은 클릭이 들립니다.

5. 마스터 FX

필터는 왼쪽이 로우패스(소리가 먹먹해짐), 오른쪽이 하이패스(저음이 빠짐)이고 가운데가 OFF입니다. 딜레이는 템포에 맞춘 에코, 리버브는 잔향, 마스터 볼륨은 전체 크기입니다. 슬라이더는 트랙을 짚은 자리로 바로 이동합니다.

6. 홈 화면에 추가

Safari 공유 버튼 → 홈 화면에 추가를 하면 주소창 없이 전체화면 앱처럼 열립니다. 한 번 열면 인터넷 없이도 동작합니다.
